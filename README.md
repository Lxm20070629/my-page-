> 人工智能学院"数字忆长征，AI 启初心"主题党日活动作品
> 形式三：长征精神红色网页（源码 + 截图 + 设计说明）

## 怎么看这个网页

直接双击 `源码/index.html` 即可在浏览器中打开，**不需要安装任何环境，也不需要联网**。

- 推荐浏览器：Edge / Chrome / Firefox / Safari 的较新版本
- 建议窗口宽度：≥ 1100px 体验最佳；手机端也已适配（最小 375px）

## 怎么分享给别人看

### 电脑上

| 方式 | 做法 |
| --- | --- |
| 直接打开 | 双击 `源码/index.html` |
| 桌面入口 | 把 `数字忆长征-AI启初心.url` 拖到桌面，以后双击即看 |
| 发给别人 | 发送 `数字忆长征-AI启初心（作品提交包）.zip`，对方解压后双击 `源码/index.html` |

> 注意：`index.html` 必须和 `style.css`、`script.js` 放在同一个文件夹里，单独把 html 拖出来会变成无样式白页。

### 手机上（微信）

**微信里直接点开 `.html` 文件是打不开的**，微信会把它当普通文件下载、不解析网页。手机上要看，必须先把网页放到网上拿到网址：

1. 把 `源码` 文件夹整个上传到免费静态托管，推荐 **Netlify Drop**（`app.netlify.com/drop`，拖入文件夹即得网址）或 **Gitee Pages**；
2. 把网址发到微信，对方点开即可在手机浏览器正常浏览；
3. 也可以生成二维码，让对方用微信「扫一扫」直接打开：

```bash
python 说明/_tools/make-share.py https://你的网址/
```

运行后会重新生成提交包、桌面入口，并生成 `手机扫码二维码.png` 和带二维码的 `分享指南.html`。

> 语音讲解功能依赖浏览器的语音合成，部分手机浏览器或微信内置浏览器不支持，电脑端 Edge / Chrome 可正常朗读。


两个脚本最近一次运行均为全部通过。自测覆盖：脚本无异常执行、终端逐字输出完整、路线节点与事件列表数量、
精神卡片与语音按钮数量、答题题目渲染、Canvas 首帧绘制、动画帧执行、路线站点坐标与进度序列正确性，
以及性能项（静态底图缓存生效、稳定帧内不重建渐变、不使用 shadowBlur）。

## 技术要点

- 纯原生 HTML5 + CSS3 + JavaScript，无任何第三方库，可离线运行
- Canvas：经纬度线性投影 + Catmull-Rom 样条平滑 + 累计弧长等速行进
- `IntersectionObserver` 驱动滚动动效，区块离开视野自动暂停，节省性能
- Web Speech API 实现中文语音讲解，含能力检测与异常兜底
- 终端输出：逐字翻转样式类（不重建 DOM）+ 容器高度锁定 + 字号自动适配
- 完整的深浅色主题变量、响应式断点、键盘可操作与 `prefers-reduced-motion` 适配
- `@media print` 打印样式，可直接"另存为 PDF"

## 流畅度优化（v2）

- **静态底图离屏缓存**：路线图的底色、地形、网格、比例尺只绘制一次，动画每帧仅一次 `drawImage`
- **光晕贴图化**：去掉 `shadowBlur`，改用预渲染光晕贴图叠加
- **路径预计算**：坐标展开为扁平数组 + 进度数组，用二分查找确定本帧绘制范围；虚线底纹抽稀到 1/3
- **少写字**：站名只画当前站点与悬停站点，单帧文字绘制由 12 次降到 1—2 次
- **重绘合并**：所有交互重绘合并到同一 `requestAnimationFrame`，同帧多次请求只画一次
- **合成层动画**：进度条改 `transform: scaleX()`、出现动画用 `translate3d`、翻面卡片声明 `will-change`
- **按需降载**：手机端降低像素密度与粒子数、移动端关闭毛玻璃、窗口缩放防抖、后台自动暂停动画
- **渲染隔离**：各板块加 `contain: layout paint style`，把重排重绘限制在板块内部
- **终端不抖动**：整行字符一次性建好、逐字只改类名，行宽固定；容器高度锁定，输出不撑高卡片
